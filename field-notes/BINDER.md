# Runnable field notes

Open `notes/hello/hello.ipynb` or
`notes/python-fsl-environment/environment.ipynb`, choose the **Field notes**
kernel, then **Restart Kernel and Run All Cells**.

The Binder session is temporary. Download edited notebooks before leaving.
Do not upload private scans, credentials, or unpublished research data.
The public service may queue or fail to start; source downloads remain available.

This image is built from locked Python and native packages in this repository.
It is not Neurodesk: local Neurodesk is an independent execution option.
The FSL subset is for non-commercial research/education, subject to the upstream
FSL license: https://fsl.fmrib.ox.ac.uk/fsl/docs/license.html
Installed package license notices are preserved. The repository's license does
not replace the licenses of its dependencies.

The sample data are synthetic. No full MRI workflow or clinical result is
validated by this demonstration.
